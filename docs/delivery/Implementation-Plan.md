# Implementation Plan

## 阶段计划
1. 工程骨架阶段
   - 初始化前端、后端、Worker、Docker Compose、环境模板、基础测试框架
2. 核心链路阶段
   - 完成账户与来源、上传会话、导入状态机、台账入库、证据引用
3. 分类与报表阶段
   - 完成分类树、规则引擎、批量确认、月报快照与下钻
4. AI 与审计阶段
   - 完成受控问答工具、AI 助手页面、运行审计与引用展示
5. 集成与交付阶段
   - 完成联调、测试报告、验收报告、人工审查指南

## MVP 优先级
- P0：工程骨架、鉴权、账户与来源、上传、导入状态机、去重、台账、证据链
- P1：分类学习、月报快照、AI 问答、审计日志
- P2：OCR 强化、投资体检增强、更多来源模板

## 技术任务清单
- 初始化 React + TypeScript + Vite 前端骨架
- 初始化 FastAPI + SQLAlchemy + Alembic 后端骨架
- 初始化 Taskiq Worker 与 RabbitMQ 集成
- 建立 Docker Compose 和 `.env.example`
- 建立账户、导入、台账、分类、报表、AI 数据模型
- 完成上传直传 R2 与导入作业确认链路
- 完成导入状态机、错误处理、重试与复核
- 完成台账查询、详情与证据抽屉
- 完成分类确认与最近批次回滚
- 完成月报快照生成与下钻
- 完成 AI 受控问答接口与引用展示

## 依赖关系
- 工程骨架先于业务实现
- 数据模型与迁移先于导入状态机
- 导入状态机先于台账与分类
- 台账与分类先于月报与 AI
- 所有业务功能先于联调和验收

## 风险
- OCR 与 PDF 解析效果依赖真实样本
- R2 与 AI Provider 凭据尚未就绪
- 空仓从 0 到 1 的脚手架量较大，需要严格控制范围

## 里程碑
- M1：工程骨架可启动
- M2：完成导入到台账的主闭环
- M3：完成分类与月报
- M4：完成 AI 问答与审计
- M5：完成集成、测试与交付文档

## 验收方式
- 每个里程碑需有可运行结果
- 关键领域规则需有自动化测试
- 前后端关键路径需通过浏览器或集成验证
- 所有交付文档需与实现同步
