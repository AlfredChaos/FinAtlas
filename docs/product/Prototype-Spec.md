# Prototype Spec

## 1. 页面分区

### 1.1 首页 Dashboard
- 顶部：月份切换、快捷上传、全局问答入口、异常提醒
- 主区上半：净资产、收入、支出、结余、储蓄率、待处理导入任务
- 主区中部：现金流趋势、导入状态卡片
- 主区下半：异常支出、待分类交易、推荐问题

### 1.2 导入中心
- 左侧：来源与账期选择、文件上传面板
- 中部：导入作业列表
- 右侧：作业详情抽屉，包含状态时间线、错误信息、中间产物、待复核项

### 1.3 台账页
- 顶部：月份、账户、分类、金额区间、关键词筛选器
- 中部：交易/投资台账表格
- 右侧：证据链抽屉与编辑区

### 1.4 分类管理页
- 左侧：通用预算分类树
- 中部：规则列表与学习样本
- 右侧：命中统计、批量确认结果、回滚入口

### 1.5 月报中心
- 纵向分区：本月概览、消费结构、现金流与负债、投资概览、建议行动
- 每个模块都带“查看明细”入口

### 1.6 AI 助手页
- 左侧：推荐问题、最近会话
- 中部：对话区
- 右侧：证据引用、计算口径、数据缺口说明

## 2. 组件清单
- 指标卡片
- 趋势图卡片
- 上传面板
- 导入状态时间线
- 高密度筛选栏
- 交易表格
- 证据抽屉
- 分类树
- 规则表格
- 月报分区卡片
- AI 对话消息卡
- 证据引用卡
- 审计日志表格

## 3. 页面跳转
- Dashboard 指标卡 -> 台账页预设筛选
- Dashboard 导入状态 -> 导入中心 / 作业详情
- 导入中心作业列表 -> 作业详情
- 作业详情待复核项 -> 交易台账或复核抽屉
- 月报关键数字 -> 台账页预设筛选
- AI 回答中的引用链接 -> 对应台账页或月报页
- 分类管理命中统计 -> 台账页预设筛选

## 4. 关键交互
- 上传后立即生成作业卡片并自动打开详情
- 失败作业支持“从失败步骤重试”
- 复核项支持行内编辑、批量确认、证据联动高亮
- 月报数字点击后带筛选条件跳转
- AI 回答固定返回“结论 / 口径 / 证据 / 数据缺口”
- 批量分类确认后即时提示学习结果，并提供最近一次回滚

## 5. 表单规则
- 上传前必须选择来源类型与账期
- 仅允许 `.csv`、`.xlsx`、`.xls`、`.pdf`、`.png`、`.jpg`、`.jpeg`
- 模板映射配置中必须保证日期列、金额列和关键描述列可解析
- 手工编辑交易时必须保留来源引用，不允许生成无来源痕迹的系统内事实
- 分类规则创建时必须声明优先级与匹配模式

## 6. 空状态
- Dashboard：提示“还没有本月数据，先去导入中心上传账单”
- 导入中心：提示支持的来源与格式，并展示上传入口
- 台账页：提示调整月份或来源筛选
- 月报页：提示当前账期尚未生成快照，可手动触发
- AI 助手：提示从推荐问题开始，并声明只基于已导入数据回答

## 7. 加载态
- 指标卡使用 skeleton
- 作业详情使用步骤级 loading
- 台账表格使用行级骨架屏
- 月报分区按模块独立加载，避免整页阻塞
- AI 对话显示“正在分析数据与证据”状态

## 8. 错误态
- 上传失败：提示格式错误、网络失败或鉴权失败
- 导入失败：显示步骤、错误原因、文件与定位信息
- 月报失败：显示快照未生成原因与重试入口
- AI 失败：区分“数据不足”“工具失败”“模型失败”

## 9. 成功态
- 上传成功：显示文件摘要与作业 ID
- 导入完成：显示成功、重复、失败、待复核统计
- 分类确认成功：显示规则或映射已学习
- 月报生成成功：提示快照版本与生成时间
- AI 回答成功：高亮结论并显示引用证据数

## 10. 响应式要求
- 桌面优先
- 1440px 以上支持三栏布局
- 1024px 到 1439px 收敛为双栏
- 小屏优先保留浏览、上传状态与问答，不保证高密度编辑效率
