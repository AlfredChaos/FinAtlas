# Domain Glossary

| Term | 中文名 | 定义 | 所属上下文 | 示例 | 备注 |
|---|---|---|---|---|---|
| Account | 账户 | 承载一个可导入、可记账来源的业务对象 | 账户与来源 | 招行借记卡、中信信用卡 | 单用户版下归属于唯一管理员 |
| Source Profile | 来源配置 | 描述来源类型、账期规则、模板映射和导入策略的配置对象 | 账户与来源 | 信用卡账单周期 | 与账户绑定 |
| Import Job | 导入作业 | 一次上传后触发的异步处理实例，具备状态机和可重试能力 | 导入与证据 | 2026-05 招行流水导入 | 导入链路主控对象 |
| Import Item | 导入条目 | 从文件中抽出的行、块、表格行或 OCR 结果 | 导入与证据 | PDF 第 3 页表格行 | 可进入复核 |
| Evidence Artifact | 证据产物 | 原始文件、抽取 JSON、OCR 结果等中间产物 | 导入与证据 | OCR JSON | 存于 R2 |
| Review Case | 复核项 | 低置信度、冲突或字段缺失而需要人工确认的记录 | 导入与证据 | 金额识别不确定 | 支持人工修正 |
| Dedupe Key | 去重键 | 按来源口径生成的业务唯一标识 | 导入与证据 / 台账 | 日期+金额+对手方哈希 | 数据库唯一约束兜底 |
| Transaction | 交易 | 现金流事实记录，覆盖收入、支出、转账、还款等 | 台账 | 工资入账、信用卡还款 | 必须带证据引用 |
| Investment Trade | 投资交易 | 基金平台上的申购、赎回、分红、手续费等事实 | 台账 | 支付宝基金申购 | 默认按申请日记账 |
| Evidence Reference | 证据引用 | 从台账事实回溯到源文件定位的引用信息 | 台账 | 文件 key + 页码/行号 | AI 和报表必须依赖它 |
| Category | 分类 | 通用预算体系中的消费或财务类别节点 | 分类 | 餐饮、住房 | 支持自定义扩展 |
| Category Rule | 分类规则 | 用于自动分类的显式规则、历史映射或学习策略 | 分类 | 商户关键词命中“外卖” | 有优先级 |
| Learning Sample | 学习样本 | 用户确认分类后沉淀的训练或映射样本 | 分类 | 美团外卖 -> 餐饮 | 支持撤销最近批次 |
| Monthly Summary | 月报快照 | 某账期按固定口径生成并持久化的分析结果 | 报表与快照 | 2026-05 月报 | 不依赖实时重算 |
| Metric Version | 指标版本 | 描述月报或 AI 统计口径版本的标识 | 报表与快照 | v1-cashflow-repay-date | 保证历史可比性 |
| Agent Run | Agent 运行记录 | 一次 AI 问答或建议生成的运行审计记录 | AI 与审计 | 询问上月餐饮支出 | 记录 trace 与工具调用 |
| Citation | 引用证据 | AI 回答或报表数字关联的可点击证据集合 | AI 与审计 | 外卖支出明细链接 | 关键结论必须带引用 |
