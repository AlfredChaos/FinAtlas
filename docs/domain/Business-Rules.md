# Business Rules

| Rule ID | Rule | Context | Enforcement Location | Test Type | Acceptance Criteria |
|---|---|---|---|---|---|
| BR-001 | 所有交易、投资交易、报表和 AI 结论都必须可追溯到原始证据 | 全局 | 领域层 + 查询层 | 集成测试 | 任意关键数字与回答都可下钻到文件与 source pointer |
| BR-002 | 导入状态机只能按合法步骤前进，失败后允许从指定步骤重试 | 导入与证据 | ImportJob 聚合 | 领域单测 | 非法状态转移被拒绝；失败后重试不会越级 |
| BR-003 | 同一文件重复导入不得污染台账 | 导入与证据 / 台账 | file_hash 校验 + DB 约束 | 集成测试 | 重复上传同一文件不新增重复交易 |
| BR-004 | 同一账户下 `dedupe_key` 唯一 | 台账 | 数据库唯一约束 + 应用层判重 | 数据库测试 | 第二次写入触发跳过或唯一约束 |
| BR-005 | 低置信度、字段冲突或疑似重复必须进入复核，不得静默视为可信事实 | 导入与证据 | ImportJob / ReviewCase | 应用服务测试 | 作业进入 needs_review 并暴露复核明细 |
| BR-006 | 信用卡现金流默认按还款日进入现金流统计 | 台账 / 报表 | 报表口径服务 | 领域单测 | 刷卡日与还款日跨月时，现金流仅计入还款月 |
| BR-007 | 基金交易默认按申请日记账，并保留确认日作为可选视图字段 | 台账 | InvestmentTrade 聚合 | 领域单测 | 申请日与确认日跨月时，默认月报以申请日归属 |
| BR-008 | 分红默认按再投资处理，支持切换为现金分红 | 台账 | InvestmentTrade 聚合 | 领域单测 | 未显式指定时不增加现金流，只更新投资事实 |
| BR-009 | 分类命中优先级为显式规则 > 历史映射 > AI 候选 | 分类 | 分类策略引擎 | 领域单测 | 同时命中多层策略时结果稳定且可解释 |
| BR-010 | 最近一次批量分类操作必须可撤销 | 分类 | 批量操作服务 | 应用服务测试 | 回滚后规则、映射和受影响记录恢复 |
| BR-011 | 月报快照必须带口径版本，且历史快照可稳定读取 | 报表与快照 | 快照生成服务 | 集成测试 | 同账期同版本结果稳定；新口径生成新版本 |
| BR-012 | AI 不得直接写核心账务数据，只能通过受控工具读取或生成建议 | AI 与审计 | Agno Tool Gateway | 安全集成测试 | 无直接写数据库能力；结果返回建议和引用 |
| BR-013 | 所有写操作必须生成审计记录 | 全局 | 应用服务层 | 集成测试 | 导入、编辑、删除、批量分类均可在审计页查询 |
