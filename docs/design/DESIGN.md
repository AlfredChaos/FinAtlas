# FinAtlas DESIGN

## Design Intent
- 关键词：可信、克制、专业、可追溯、高密度但不压迫
- 视觉气质：财务驾驶舱 + 编辑式信息排版
- 交互原则：任何关键数字都应能下钻，任何异常都应能解释，任何 AI 结论都应带证据

## Layout System
- 桌面优先
- 默认三栏：左侧导航、中央工作区、右侧证据/上下文面板
- 高密度表格页面允许切换为双栏
- 卡片化用于摘要，表格与时间线用于事实和过程

## Color Tokens
- `bg/base`: 深墨蓝或冷灰背景
- `bg/panel`: 高于背景一层的卡片底色
- `text/primary`: 高对比正文色
- `text/muted`: 次级说明色
- `accent/positive`: 翠绿色
- `accent/warn`: 琥珀色
- `accent/danger`: 红色
- `accent/info`: 蓝绿色

## Typography
- 标题：稳健、略带金融产品感的 display sans
- 正文：高可读 sans-serif
- 数字：启用 tabular numbers，保证金额对齐
- 层级控制在 4 到 5 档，避免过多字号

## Spacing
- 使用 4 的倍数
- 卡片内边距优先 `16/20/24`
- 页面大区块间距优先 `24/32`
- 表格行高优先兼顾紧凑和可读性

## Components
- 指标卡：数字优先，辅以状态标签与环比箭头
- 状态时间线：用于导入步骤与处理状态
- 高密度筛选栏：固定在页面顶部或吸附区域
- 证据抽屉：统一承载来源文件、页码、片段、修正历史
- AI 回答卡：固定结构为结论、口径、引用、缺口

## Motion
- 以细微过渡为主，不做炫技动画
- 上传、状态变化、抽屉展开、问答流转需要明确动效反馈
- 错误与警告优先通过颜色和结构表达，而不是强动画

## Accessibility
- 颜色不是唯一状态表达方式
- 表格、抽屉、表单必须支持键盘操作
- 图表需提供文字摘要或 tooltip
- 错误信息需可读且可定位
